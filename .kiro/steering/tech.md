# Technical Standards

- Next.js App Router, TypeScript strict mode and Tailwind CSS.
- Use the repository's installed versions and existing conventions; inspect `package.json` before proposing dependencies.
- Prefer Server Components. Use Client Components only when browser APIs, state or interaction require them.
- Prefer semantic HTML, accessible controls and responsive layouts.
- Reuse existing components and dependencies before creating new ones.
- Avoid unnecessary dependencies, abstractions and wrapper components.
- Do not change architecture or add packages without explaining why.
- Validate changes with the scripts actually defined in `package.json`.
- Never claim a test or build passed unless it was executed successfully.
