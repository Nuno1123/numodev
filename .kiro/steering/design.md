# Design Direction

- Visual style: minimal, polished, dark, modern and editorial.
- Use the existing theme tokens and Tailwind utilities; avoid arbitrary values when a suitable token exists.
- Preserve generous spacing, clear typography and restrained motion.
- Respect `prefers-reduced-motion`.
- Ensure keyboard navigation, visible focus states, sufficient contrast and accessible labels.
- Desktop: two-column layout with profile/sidebar and main content.
- Sidebar sections: Skills, Education, Languages and Free Time; Skills is initially expanded.
- Main content: introduction, professional experience carousel/timeline and a Kiro SDD showcase.
- Mobile-specific layout decisions remain open until explicitly specified.
- Do not introduce new design libraries without approval.
